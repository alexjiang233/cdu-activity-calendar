# cdu-activity-calendar

成都大学校园活动与参与机会发现项目的早期 Demo。项目希望通过整理有依据的通知，让学生提前了解可能值得关注、参与和准备的事情。

当前只验证展示方式、搜索、分类、月份筛选和信息不确定性的表达。页面中的少量真实资料整理样例尚未完成来源和适用版本审核，不代表当前可报名机会，请勿据此报名。

这是学生自主建设的非官方项目，与学校官方通知平台无关联。原始 Word 文档、个人联系信息、本地文件路径和内部审核证据不包含在这个仓库中。

## 查看

启用 GitHub Pages 后，通过仓库设置中显示的网页地址查看。也可下载 index.html 后用浏览器打开，无需安装依赖。

## 文件

- index.html：包含必要样式和交互的演示网页。
- .nojekyll：静态网页标记。
- README.md：项目说明。

正式数据录入、事实审核、来源追溯和发布流程仍在本地验证，当前网页不提供报名、登录、投稿或自动发布功能。

仓库名称是当前工作名称，后续可以调整；项目网站地址可能随仓库改名而改变。
